# Vband USB Adapter
Used for practice CW QSOs without go to air

![WhatsApp Image 2025-08-30 at 11 43 23 (1)](https://github.com/user-attachments/assets/06087c5f-7961-42e1-ad18-1a6fc951d011)
Built using an Arduino MKR Zero I had in a drawer and a 3.5 mm jack. Please make sure, as not all Arduinos are capable of using the Keyboard.h library. Check the documentation of the model you intend to use.


![WhatsApp Image 2025-08-30 at 11 43 23](https://github.com/user-attachments/assets/a2d8600a-976c-47fe-8c65-7f45e17548a8)
Used to practice CW without going on the air. Suitable for the Vband page, Morse Invaders, and any other CW bot that works in internet browsers.
